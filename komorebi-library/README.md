# Komorebi / Haetsal Asset Library

34 reusable PNG assets for the JP and KR video pipelines.

- `backgrounds/jp`: 20 Japanese engawa/tatami backgrounds (landscape 16:9)
- `backgrounds/kr`: 4 Korean hanok toenmaru backgrounds (landscape 16:9)
- `mascot`: 8 transparent Komachi/Bori poses
- `overlay`: transparent quiz card and question-mark badge

Background images consistently reserve the left third for the mascot and leave open space to the right for titles. The transparent mascot and overlay assets can be composed on either 16:9 long-form or 9:16 Shorts layouts.
